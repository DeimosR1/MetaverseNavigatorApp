# MetaverseNavigatorApp

__A Fanmade Recreation of the Metaverse Navigator App seen in [Persona 5](https://atlus.com/persona5/) and [Persona 5: Royal](https://persona.atlus.com/p5r/?lang=en)__

*Engine Configuration

|Engine|Version|
|------|-------|
|Unity|6000.0.25f1|
____

## Function:
This proyect has these basic main functions:
* Identifying when the correct sequence of name, place and distortion is input in the correct fields.
* Save the last correct input.
* Play the song "Life Will Change" from the game.
